
# Week 03 - HTML Input Types

## 1. Text
برای دریافت متن معمولی مانند نام و نام خانوادگی استفاده می‌شود.

## 2. Email
برای دریافت آدرس ایمیل استفاده می‌شود.

## 3. Password
برای دریافت رمز عبور استفاده می‌شود و متن واردشده را مخفی نمایش می‌دهد.

## 4. Number
برای دریافت مقادیر عددی استفاده می‌شود.

## 5. Checkbox
برای انتخاب یک یا چند گزینه استفاده می‌شود.

## 6. Radio
برای انتخاب فقط یک گزینه از یک گروه استفاده می‌شود.
گزینه‌های یک گروه باید name مشترک داشته باشند.

## 7. Date
برای انتخاب تاریخ استفاده می‌شود.

## Label and ID
ویژگی for در label باید با ویژگی id در input یکسان باشد.
این ارتباط باعث می‌شود با کلیک روی عنوان، فیلد مربوطه انتخاب شود.

# Week 03 - Advanced HTML Forms

## 1. Select
برای ساخت منوی کشویی و انتخاب یک گزینه استفاده می‌شود.

## 2. Option
برای تعریف گزینه‌های داخل select استفاده می‌شود.

## 3. Optgroup
برای دسته‌بندی گزینه‌های مرتبط در منوی کشویی استفاده می‌شود.

## 4. Textarea
برای دریافت متن‌های طولانی و چندخطی استفاده می‌شود.

ویژگی rows تعداد سطرها و cols تعداد ستون‌ها را مشخص می‌کند.

## 5. Button
برای ساخت دکمه در HTML استفاده می‌شود.

### Submit
برای ارسال فرم استفاده می‌شود.

### Reset
مقادیر فرم را به حالت اولیه برمی‌گرداند.

### Button
یک دکمه معمولی است و به‌صورت پیش‌فرض فرم را ارسال نمی‌کند.

## 6. Required
این ویژگی فیلد را اجباری می‌کند.
اگر فیلد خالی باشد، مرورگر اجازه ارسال فرم را نمی‌دهد.

## 7. Placeholder
یک متن راهنما داخل فیلد نمایش می‌دهد.
با شروع تایپ، این متن ناپدید می‌شود.

## 8. Minlength
حداقل تعداد کاراکترهای مجاز را مشخص می‌کند.

## 9. Maxlength
حداکثر تعداد کاراکترهای مجاز را مشخص می‌کند.

## 10. Name
نام فیلد را برای ارسال اطلاعات فرم مشخص می‌کند.
بدون name مقدار فیلد در داده‌های ارسالی فرم قرار نمی‌گیرد.

## 11. Label and Placeholder
Label عنوان اصلی فیلد است.
Placeholder فقط متن راهنما است و جایگزین Label نیست.

## 12. Button and Input Submit
هر دو برای ارسال فرم قابل استفاده هستند.
Button انعطاف بیشتری برای قرار دادن محتوا دارد.

## 13. Form Validation
مرورگر با ویژگی‌هایی مانند required و minlength
می‌تواند قبل از ارسال فرم، اطلاعات واردشده را بررسی کند.

## Experiment Results
- Required: مرورگر برای فیلد خالی پیام خطا نمایش داد.
- Minlength: ورودی کوتاه‌تر از حد مجاز پذیرفته نشد.
- Maxlength: ورود کاراکتر بیشتر از حد مجاز محدود شد.
- Placeholder: با تایپ کردن ناپدید شد.
- Reset: اطلاعات فرم به حالت اولیه برگشت.
- Submit: پس از معتبر شدن فیلدها، فرم ارسال شد.
- Button: پیام کلیک نمایش داده شد.
- Select: گزینه‌ها با optgroup دسته‌بندی شدند.
