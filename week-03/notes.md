
# Week 03 - HTML Input Types

## 1. Text
برای دریافت متن معمولی مانند نام و نام خانوادگی استفاده می‌شود.

## 2. Email
برای دریافت آدرس ایمیل استفاده می‌شود.

## 3. Password
برای دریافت رمز عبور استفاده می‌شود و متن واردشده را مخفی نمایش می‌دهد.

## 4. Number
برای دریافت مقادیر عددی استفاده می‌شود.

## 5. Checkbox
برای انتخاب یک یا چند گزینه استفاده می‌شود.

## 6. Radio
برای انتخاب فقط یک گزینه از یک گروه استفاده می‌شود.
گزینه‌های یک گروه باید name مشترک داشته باشند.

## 7. Date
برای انتخاب تاریخ استفاده می‌شود.

## Label and ID
ویژگی for در label باید با ویژگی id در input یکسان باشد.
این ارتباط باعث می‌شود با کلیک روی عنوان، فیلد مربوطه انتخاب شود.
